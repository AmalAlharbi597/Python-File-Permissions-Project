# Python-File-Permissions-Project
 This project demonstrates how to use Python to change file or directory permissions in a Linux environment. It includes a script (change_permissions.py) that utilizes the os module to modify permissions, ensuring a secure and organized approach to managing file access rights. 


 Features:
-Changes permissions of a file or directory to rwxrwxr-x (775).
-Utilizes Python's built-in os.chmod function for permission handling.
-Provides a simple and effective way to manage file permissions programmatically.

How It Works:
The script imports the os module for file system operations.
It sets the desired file or directory path using the file_path variable.
The script applies the chmod function with permission mode 0o775, equivalent to rwxrwxr-x.
Upon successful execution, a confirmation message is displayed.

Usage:
Clone or copy the project files to your desired directory.
Edit the file_path variable in the change_permissions.py script to point to your target file or directory.
